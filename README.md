# Toqa Tamer — Portfolio

A modern dark + purple personal portfolio for Toqa Tamer, combining Cybersecurity and Data Analytics.

## Included sections
- Home
- About
- Skills
- Projects
- Certifications
- Contact

## Tech
- HTML5
- CSS3
- JavaScript
- Google Fonts
- Responsive design
- Dark/Light mode
- Project filtering
- Scroll animations

## Run locally
Open `index.html` in a browser.

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Go to **Settings → Pages**.
4. Select the main branch and root folder.
5. Save and open the generated Pages URL.
